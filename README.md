# ESP8266 Waveshare 7.5" epd7in5bc — 中文日历 + 三色自定义图 + 花体时钟

## 产品类型
嵌入式固件：ESP8266 + Arduino，驱动 Waveshare 7.5 寸 640×384 墨水屏（官方驱动 **epd7in5bc**），实现日历时钟墙表/桌摆显示。

## 硬件
- **MCU**：ESP8266
- **显示屏**：Waveshare 7.5" 640×384，驱动文件 **epd7in5bc**（黑白红）
- **接线**：BUSY / RST / DC / CS / CLK / DIN 等 **不写死引脚**；在工程内以 **全局变量或集中配置头文件**（如 `config_pins.h`）定义，默认值可留空或占位，便于用户按实际接线修改。

## 画面布局（640×384）
| 区域 | 尺寸（约） | 内容 |
|------|------------|------|
| 上左 | 384×307（宽 3/5 × 高 4/5） | **中文日历**（公历月视图，**周日**为一周起始，高亮今日） |
| 上右 | 256×307（宽 2/5 × 高 4/5） | **自定义图片**（黑白红三色），数据来自同目录 **单个** `.h` C 数组文件 |
| 下 | 640×77（高 1/5） | 居中 **花体艺术字** 数字时钟，格式 **`xx:yy（UTC+8）`**，精确到分钟 |

纵向总体 **4:1**（上:下）；上半 **3:2**（左:右）。

## 刷新策略
- **全屏刷新**：日历 **日期** 变化时（含跨日、首次完整绘制日历）。
- **局部刷新**：**分钟** 变化时，仅刷新 **下方时钟区域**（不整屏刷）。
- 建议：每日至少一次全刷以减轻残影（可在日期变化全刷时满足）。

## 时间与网络
- **WiFi + NTP** 自动对时；固定时区 **UTC+8**（无夏令时）。
- WiFi 凭证：`secrets.h` 或宏配置（SSID / 密码），不写死真实密码进仓库。
- 可选：周期性 NTP 重同步（如每 6 小时）。

## 自定义图片
- 单文件，例如 `custom_image.h`，与主程序同目录。
- 组织方式为 **C 数组**（及宽高等元数据），符合 epd7in5bc 所需的 **黑 / 白 / 红** 通道数据（按 Waveshare 官方示例：黑白缓冲 + 红色缓冲或等价结构）。
- 画布目标区域 **256×307**；用户可替换该文件而不改主逻辑。

## 时钟字体
- **花体/艺术字** 通过 **预置位图字模**（flash 中的 C 数组）实现，非运行时 TTF。
- 字符集覆盖数字、`:`、括号及 `UTC+8` 相关展示所需字符。

## 日历（中文）
- 界面文案中文（年、月、星期等）。
- **一周从周日开始**。
- 公历月历格；突出 **当天**。

## 技术栈
- **Arduino** ESP8266 Core（3.x 兼容）
- **Waveshare 官方** 7.5" 套件中的 **epd7in5bc** + **DEV_Config**（引脚从全局配置注入或封装为可改宏/变量）
- **time.h** / `configTime` + NTP，UTC+8
- 构建：Arduino IDE 或 PlatformIO，**本地烧录**，无云端部署

## 工程结构（建议）


## 验收标准
1. 配置 WiFi、引脚、NTP 后上电，时间显示正确（UTC+8，分钟级）。
2. 布局符合 4:1 与上区 3:2；左日历中文、周日起算；右区显示三色自定义图；下区居中花体 `xx:yy（UTC+8）`。
3. 分钟变化仅下区局部刷新；日期变化触发全屏刷新（含日历更新）。
4. 引脚均在全局配置处修改即可，无需改驱动核心逻辑。
